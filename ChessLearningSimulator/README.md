# Chess Learning Simulator

A full chess game and learning tool in a single self-contained `index.html` file — no build step, no dependencies, just open it in a browser.

## Features

- **Practice mode** — move both sides yourself to explore openings and tactics
- **Vs Computer** — play against a bot with Easy / Medium / Hard difficulty (minimax with alpha-beta pruning)
- **Two Player** — local pass-and-play on one device
- **Learning Mode** — toggle on to see every legal move highlighted on the board whenever it's a player's turn
- Full rule support: castling, en passant, pawn promotion, check/checkmate/stalemate detection
- Move history, captured-piece tray, undo, board flip, light/dark theme toggle

## Running it

Just open `index.html` in any modern browser. Everything (engine, bot AI, and UI) is bundled into the one file.
